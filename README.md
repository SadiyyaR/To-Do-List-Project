📝 My To-Do List

A simple and user-friendly To-Do List Web Application developed using HTML, CSS, and JavaScript.

🚀 Project Overview

My To-Do List helps users organize their daily activities by adding and managing tasks in one place.

✨ Features

- Add new tasks
- Delete tasks
- Simple and attractive user interface
- Tasks remain saved after refreshing the page
- Easy to use

🛠️ Technologies Used

- HTML – Structure
- CSS – Styling and Design
- JavaScript – Functionality
- GitHub Pages – Website Hosting
